# Mood Tracker

A simple **GUI-based Mood Tracker** built using Python's Tkinter library. This application allows users to select their current mood from a set of options, each accompanied by an image, providing a visual and interactive experience.

## Features
- Select your current mood from options like **Happy, Sad, Angry, or Nothing**.
- Each mood option comes with a **representative image** for better visual experience.
- Simple and clean **Tkinter GUI** design with intuitive layout.
- Easily extendable to track moods over time or connect to a database.

## Technologies
- **Python**
- **Tkinter** (for GUI)
- **PNG Images** for mood representation
